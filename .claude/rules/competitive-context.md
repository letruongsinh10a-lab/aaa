# Competitive Context

## What We're Beating

**nhaitopik.com** — the main Vietnamese competitor for TOPIK learners.

| Their weakness | What we do instead |
|---|---|
| Zero images, icons, illustration — looks like a wiki | Every section has visual elements, illustrations, animated demos |
| No visual identity — flat colors, no personality | Dark Premium design system with coral accent, consistent tokens |
| No animations or transitions — feels static | Framer Motion on every section reveal and interactive element |
| Generic typography — no hierarchy | Instrument Serif (editorial) + Plus Jakarta Sans, bold scale |
| Weak CTAs — no urgency | Prominent coral primary CTAs, social proof, streak urgency |
| No progress / gamification — no reason to return | Full SRS, streak, XP, level system, weekly leaderboard |
| Poor mobile experience | Mobile-first layout, swipe gestures, 44px touch targets |
| Emotionally flat — no excitement to learn | Delight animations, achievement toasts, confetti on session end |

## World-Class Benchmarks to Reference

When building any feature, ask: "Does this feel like one of these products?"

| Product | What to steal |
|---|---|
| **Linear.app** | Dark UI polish, pixel-perfect spacing, border style, typography |
| **Vercel.com** | Gradient accents, dark premium feel, bold section headers |
| **Raycast.com** | Hero section quality, feature showcase, motion quality |
| **Duolingo** | Streak mechanic, XP system, hearts, level progression, mascot energy |
| **Drops app** | Vocabulary card visual design, minimalist interaction, color use |
| **Brilliant.org** | Progress visualization, course structure, interactive learning |
| **Framer.com** | Animation quality, hero motion, modern layout |
| **Anki** | SRS algorithm correctness (but not the design — ours is far better) |

## Design Philosophy

> Every screen must feel like a Silicon Valley product, not a Vietnamese education website.

- Premium and characterful — has a distinct visual voice
- Screenshot-worthy — users share screens because they look good
- Emotionally engaging — creates excitement, not obligation
- Focused — never cluttered, never noisy
- Fast — snappy interactions, no lag between actions

## Tone of Voice

- Vietnamese copy: confident, short, punchy — no exclamation marks in body copy
- Korean terms: always shown in Hangul (not just romanization)
- Error states: encouraging, not punishing
- Achievement moments: celebratory, but not overwhelming
